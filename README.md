## 💈 Core Architectural Innovations

- **Kinetic Hover-Reveal Gallery:** Custom high-framerate cursor-following portrait reveal animation showcasing master barber craftsmanship.
- **AI Haircut Style Advisor:** Intelligent interactive advisor helping clients select optimal hairstyles matching face topology.
- **Real-Time Booking & Deposit Processing:** Integrated booking scheduler with automated slot verification and Mercado Pago payment webhooks.
- **E-Commerce Product Showcase:** Curated catalog of artisan pomades, beard oils, and hair care products with shopping cart flows.

## 🚀 Quickstart & Development

```bash
# Clone the repository
git clone https://github.com/ExeDevCentral/pelu-rosario.git
cd pelu-rosario

# Install dependencies
npm install

# Start Next.js development server
npm run dev
```

Visit `http://localhost:3000` to experience the boutique web application.
